# UI 重做 · Backlog

设计稿里**画了、但应用还没有那个能力**的部分。按任务要求，它们一律先以设计稿的
「占位」形态落地（画出来但禁用 / 说明未实现），能力本身记在这里。

同时记录设计稿与现有行为**冲突**的地方，以及裁决的理由 —— 重做只动表现层，
凡是会改变行为的差异都停在这份清单上，不在代码里悄悄改掉。

## 二、与现有行为冲突，裁决在此

| # | 冲突 | 裁决 |
|---|---|---|
| C1 | 03 的画板仍画着拆分前的旧外壳（28px 系统标题栏 + 50px 应用工具条、侧栏 236–240） | **外壳一律以 02 为准**（统一 48px、侧栏 244、右面板 352）。03 只取主内容区规格 |
| C2 | 05.4 浮层与独立窗口写「保留最近 30 天」，抽屉写「保留 7 天」 | 以 `HistoryService.retentionDays = 7` 为准 —— 文案必须说真话 |
| C3 | 05.2 页脚勾选项写「同时备份原文件夹快照」 | 应用的 `backup` **不复制任何东西**，它只决定是否记录撤销清单。沿用现有 l10n 文案，只取设计稿的版式 |
| C4 | 04.3 的图片角色菜单写死了 poster / fanart / folder / thumb 四项 | 以 `ImageRole` 枚举为准，且**每个角色只出现一次** —— 两个角色映射到同一个 Jellyfin 类型会互相覆盖 |
| C5 | 1.3b 要求窗口圆角 14–18 | 不在 Flutter 侧裁剪：两个系统对无边框窗口本来就自己倒角，再套 `ClipRRect` 只会在四角露出不透明底色 |
| C6 | 1.4e 的弹层出现动画与 Material 的缩放入场 | 按 1.4f「不做缩放、不做弹性曲线」，全部改成淡入 + ≤4px 位移 |

## 三、本次重做主动补的、设计稿没画的

设计稿是按整页画的，没有覆盖「一个整页路由盖住主顶栏之后会怎样」。

- **二级顶栏**（`SecondaryTitleBar`）：隐藏系统标题栏之后，`Navigator.push` 的整页
  界面会连拖拽区和窗口按钮一起盖掉 —— 设置、历史、进度页都会变成一个既不能移动
  也不能关闭的窗口。三个页面现在戴同一条 48px。
- **状态栏分工**：3.1 的面板页脚和 2.6 的状态栏都要写计数，两者对「已选」的口径
  不同（面板把聚焦行算作 1）。状态栏改为只讲总大小与 AI 状态。

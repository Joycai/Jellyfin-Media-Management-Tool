# 02 · 程序外壳（Shell）

来源：`02-Shell.dc.html`。取值引用 [01 通用标准](01-foundations.md)。

## 2.1 选型

方案 A「统一顶栏」：一条 48px 顶栏同时承载品牌、一级分区 Tab、全局搜索、动作图标与窗口按钮。
Windows 与 macOS 共用同一条，仅窗口控件位置不同。

## 2.2 Windows 顶栏

从左到右：`12px 左安全边距` → 品牌区 → 分隔线 → Tab 区 → 弹性搜索区 → 动作区 → 分隔线 → 窗口按钮区（贴右边）。

### 尺寸与间距

| 项 | 值 |
|---|---|
| 顶栏总高 | 48 |
| 最大化时 | 48 + 8 顶补 |
| 左安全边距 | 12 |
| 右安全边距 | 0（按钮贴边） |
| Logo | 26 · r7，`linear-gradient(135deg,#5b8dff,#9d7bff)`，白色 `J` 12/700 |
| Logo → 产品名 | 9 |
| 产品名 | 12.5 / w600 |
| 分隔线左右 | 12 / 12（1 × 20，暗 white 10% / 亮 ink 12%） |
| Tab 高 / 内距 / 间隔 | 32 / `0 12` / 4 |
| Tab 圆角 / 字号 | 8 / 12.5 |
| 任务徽标 | 16 圆 · 9.5 mono / 700，accent 实底白字 |
| 搜索框 | h32 · r10 · 宽 200–460（居中，`flex:1` + `max-width`） |
| 搜索左右留白 | 16 |
| 动作图标 | 32 · r9 · gap 6（历史 🕘 / 刷新 ↻ / 设置 ⚙） |
| 窗口按钮 | 46 × 48 · r0 |

Tab 激活态：暗 `accent 18%` + 描边 `accent 32%` + `inset 0 1px 0 rgba(255,255,255,.12)`，文字白 600；
亮 `accent 14%` + 描边 `accent 30%` + `inset 0 1px 0 rgba(255,255,255,.8)`，文字 `#1a3a8f`。
非激活文字暗 white 62% / 亮 ink 68%，图标 opacity .8。

### 描边 · 分隔 · 投影

| 项 | 值 |
|---|---|
| 顶栏底边 暗/亮 | white 7% / ink 7% |
| 组间分隔线 | 1 × 20 · 10% / 12% |
| 玻璃底 暗/亮 | 0.58 / 0.62 + blur 28 saturate 180 |
| 失焦玻璃底 | 0.42 / 0.50 |
| 顶栏投影 | 无（只用 1px 底边） |
| Logo 投影 | `0 4 10 accent 30%` |

### 窗口按钮

| 项 | 值 |
|---|---|
| 命中区 | 46 × 48（≥ 系统 46×32） |
| 图标尺寸 / 线宽 | 10 × 10 / 1 |
| 图标色 亮/暗 | ink 70% / white 70% |
| 悬停底 暗色 | white 9% |
| 悬停底 浅色 | ink 7% |
| 按下底 | 悬停 × 0.6 不透明度 |
| 关闭悬停 | `#c42b1c` · 图标转白 |
| 关闭按下 | `#b22215` |
| 过渡 | 80ms linear |

悬停底色铺满整个 46×48 矩形、**不加圆角** —— 这是它与左侧 32×32 圆角动作按钮唯一也是最强的区分信号。
最大化按钮须在 `WM_NCHITTEST` 返回 `HTMAXBUTTON`，否则 Snap Layouts 不弹出。

### 伸缩规则

| 区 | 规则 |
|---|---|
| 品牌区（固定） | Logo 恒定 26；产品名 **< 1180 隐去**，不做省略号 |
| Tab 区（固定） | 永不压缩、永不省略（中文 ≈ 248，英文 ≈ 262） |
| 搜索区（弹性） | 唯一 flex 项，200–460；到 200 后先丢快捷键提示，再丢占位长句 |
| 动作区（固定） | 3 × 32 + 2 × 6 = 108；溢出时按 历史 → 刷新 的顺序折入设置菜单 |
| 窗口区（锁定） | 138 永不参与压缩，最大化时其下方与右侧不得出现任何应用内容 |

## 2.3 窗口状态

### 最大化

- 窗口圆角 14 → 0，外描边去掉，玻璃底不透明度 0.58 → 0.72。
- Flutter 侧需读取 Windows 最大化时向外溢出的 8px 边框并加到 body 内边距，避免主体被裁切。
- 窗口按钮顶到 y=0、右到 x=0，命中区覆盖屏幕角落。
- 右侧 138px 内不摆放任何应用控件。

### 失焦

- 文字与图标不透明度整体乘 **0.55**。
- 激活 Tab 的强调色底换成中性 white 5%。
- 任务徽标保留强调色但降到 55%（它代表后台仍在运行）。
- 玻璃底 0.58 → 0.42，分隔线 0.10 → 0.06。
- 窗口按钮图标降到 38%，悬停时立刻恢复满对比。

## 2.4 拖拽热区与性能模式

### 拖拽

- 整条顶栏铺一层拖拽区，所有控件以「打洞」方式覆盖在上层。
- 双击拖拽区 = 最大化 / 还原；右键拖拽区 = 系统窗口菜单；控件上的双击与右键不冒泡。
- 搜索框与 Tab 之间、动作组与分隔线之间各留 ≥ 12px 可拖拽缝隙；
  最窄 1024 时仍保证 **≥ 160px** 连续可拖拽面积。

### 性能模式（无模糊替代）

去掉 backdrop-filter 后半透明底会透出渐变，对比度塌到 2:1。替代方案是把玻璃层换成
**不透明实色** —— 「主题背景色与玻璃色按玻璃不透明度预混合」的常量。

> 落地说明：下面这套常量挂在**玻璃强度滑杆的 `0` 档**上，没有单独的「性能模式」开关。
> 两个控件会互相矛盾（「性能模式开着 + 强度 50」不表示任何东西），理由见
> [`docs/architecture/rendering-and-theming.md`](../../architecture/rendering-and-theming.md) 的「Settings screen」一节。

| 项 | 深色 / 浅色 |
|---|---|
| 顶栏底色 | `#171A2B` / `#F4F6FB` |
| 控件底（原 white 6%） | `#21253A` / `#E7EBF4` |
| 激活 Tab 底 | accent @ 22% 混入底色 |
| 底边分隔线 | 不透明度 × 1.4 |
| Logo 投影 | 去掉 |

### 强调色可替换

全稿只有四处用到强调色：Logo 渐变、激活 Tab 底与描边、任务徽标、搜索聚焦环。
它们一律以 accent 的不透明度派生（18% / 32% / 100% / 55%），不写死色值；
文字始终用中性墨色而非强调色。任务徽标是唯一强调色实底 + 白字的组合，
要求 accent 亮度 ≤ 0.72，超过时自动改用墨色文字。

## 2.5 macOS 顶栏

同一条 48px。右端窗口按钮换成左端系统交通灯：

- 左侧预留 **84px**（交通灯 3 × 12 圆点、间距 8，起始 x=20），其后 12px 空隙再接品牌区。
- 腾出的 138px 全部还给搜索与动作区。
- 快捷键提示写 `⌘K`。
- **全屏**：交通灯随菜单栏隐藏，左侧预留 84 → 12，240ms 缓动回收。
- **失焦**：交通灯转 `rgba(255,255,255,0.22)` 灰点，其余同 Windows 失焦规则。

## 2.6 布局骨架

`48 顶栏 / 244 侧栏 / flex 主内容 / 352 右面板 / 28 状态栏`

### 侧边栏

- 宽 **244**，可拖拽 200–360。
- 行高 32，圆角 8，内距 `7 / 10`。
- 分组标题 10px · 600 · 0.08em。
- 折叠断点 **< 1180 → 64 图标栏**。
- 底部固定：存储占用条。

### 主内容区

- flex · min-width 520 · 左右内距 22。
- 工具条 / 面包屑 h36 · 与列表间距 12。
- 列表行高 34；滚动容器只在此层。

### 右侧面板

- 宽 **352**，可关闭，状态随分区记忆。
- 承载：AI 助手 / 详情 / 任务队列。
- **小于 1400 时默认收起，改为浮层**。

### 状态栏

- h **28** · 仅文字与进度，无按钮。

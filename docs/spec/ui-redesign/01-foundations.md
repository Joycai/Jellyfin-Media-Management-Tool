# 01 · 通用标准（Foundations）

来源：Claude Design 项目 `Jellyfin媒体库整理工具` / `01-Foundations.dc.html`。
所有取值以本页为准，功能页只引用编号。Dart 实现见 `lib/theme/design_tokens.dart`。

## 1.1 色彩

两套主题共用一组强调色。底层用半透明玻璃叠在渐变窗口底上，强调色只以 16–22% 的底色出现，
文字与图标始终用不透明实色，保证 4.5:1 对比。

### 深色主题 · 底层

| 角色 | 取值 |
|---|---|
| 窗口底 | `#0a0b14` + 两层 radial 渐变（蓝 28% / 紫 22%） |
| 顶栏 | `rgba(10,11,22,.58)` · blur 28 saturate 180 |
| 侧栏 / 面板 | `rgba(12,13,24,.45)` · blur 40 |
| 控件底 | white 5% · 悬停 white 10% · 描边 white 7% |
| 选中态 | accent 16% + 描边 accent 24% |

文字：标题 `#fff` · 正文 white 86% · 次要 white 62% · 辅助/单位 white 45% · 禁用 white 32%

### 浅色主题 · 底层

| 角色 | 取值 |
|---|---|
| 窗口底 | `#eef0f6` + radial 渐变 |
| 顶栏 | white 62% · blur 28 saturate 180 |
| 侧栏 / 面板 | `#f2f4f9` · blur 40 |
| 卡片 / 行 | white 85% + 描边 `rgba(0,30,80,.08)` |
| 选中态 | accent 14% + 描边 accent 30% |

文字：标题 `#1a1d29` · 正文 ink 88% · 次要 ink 75% · 辅助/单位 ink 50% · 禁用 ink 35%
（ink = `rgba(20,30,60,·)`）

### 强调色与语义色

| 名称 | 纯色 | 浅底文字色 | 用途 |
|---|---|---|---|
| 主强调 Accent | `#5b8dff` | `#3b5bc0` | 选中、主按钮、进度、链接、当前分区 |
| AI 紫 | `#9d7bff` | `#6b45c9` | AI 生成、模型相关、智能建议 |
| 成功 / 刮削 | `#5fd3bc` | `#1d7a68` | 完成、已匹配、可撤销角标、标注线 |
| 警告 | `#ffb478` | `#8a5116` | 低置信匹配、需人工确认、覆盖提示 |
| 危险 | `#ff7896` | `#a32449` | 删除、失败、不可撤销 |

规则：
- 一屏最多出现两种语义色。
- 语义色不做渐变；只有品牌标记（J 图标）用 `linear-gradient(135deg,#5b8dff,#9d7bff)`。
- 深色背景上的语义文字直接用纯色本身，不降不透明度。

## 1.2 字体与排版

界面字体 Inter，中文回落 PingFang SC / Microsoft YaHei；一切定长数值（路径、大小、时间、
快捷键、色值）用 JetBrains Mono。

### 字阶

| 规格 | 用途 |
|---|---|
| 36 / 700 / -0.02em | 页面大标题（仅规范页） |
| 22 / 700 | 分区标题、详情页主标题 |
| 15–16 / 600 | 卡片标题 / 对话框标题（每个容器只有一个） |
| 13 / 400–600 | 正文与列表主文案（文件名、条目名） |
| 12.5 / 400–600 | 界面控件文字（按钮、Tab、菜单项） |
| 11.5 / 400 | 次要说明与副文案（列表第二行） |
| 11 / 500 · mono | 路径、数值、快捷键 |
| 10 / 600 / 0.08em | 分组标题 GROUP LABEL（侧栏与列表分组） |

### 排版规则

- 字间距全局 `-0.005em`，22px 以上标题收到 `-0.02em`；中文不额外收紧。
- 行高：密集列表 1.5，正文 1.7，说明段落 1.85–1.95。
- 不使用斜体；强调一律用字重 600 或颜色。
- 文件名、路径过长时中间省略（`…`），保留扩展名与末级目录；不在行尾截断。
- 数字与单位之间留一个空格：`38.2 GB`；时间 24 小时制 `14:22`，日期 `2026-09-12`。
- 一级分区标签中文最长 3 字（文件 / 媒体库 / 任务），英文最长 1 词。
- 英文按钮文案按 1.35 倍宽度预留；德/法按 1.6 倍校验不换行。
- 中英混排不手动加空格。

## 1.3 间距 · 圆角 · 尺寸 · 层级

基准步进 2px，常用 4 / 6 / 8 / 10 / 12 / 16 / 22 / 24。

### 间距

| 值 | 用途 |
|---|---|
| 4 | 图标与文字、徽标与标签 |
| 6 | 同组按钮之间 |
| 8 | 图标与标签、行内元素 |
| 10–12 | 控件左右内距、列表行内距 |
| 16 | 卡片内元素间距、侧栏内距 |
| 22–24 | 卡片与对话框内距、主内容区左右 |
| 32–40 | 区块之间、空状态四周 |

### 圆角

| 值 | 用途 |
|---|---|
| 4–6 | 快捷键胶囊、小标签 |
| 7–9 | 按钮、图标底、侧栏行、类型图标 |
| 10 | 输入框、搜索框、列表行 |
| 12 | 弹层、内容卡、对话框 |
| 14–18 | 窗口（macOS 12 / Windows 10） |

嵌套时内层圆角 = 外层 − 内距，最小 6；窗口最大化时窗口圆角归零，内部不变。

### 控件高度

| 值 | 用途 |
|---|---|
| 24 | 行内小按钮、标签 |
| 28 | 次级按钮、状态栏 |
| 32 | 标准按钮、输入框、图标按钮、Tab |
| 34 | 文件列表行 |
| 44 | 双行列表行（历史、任务） |
| 48 | 统一顶栏 |

窗口按钮是唯一例外：`46 × 48` 无圆角贴边。

### 层级 · 投影与模糊

| 级 | 用途 | 投影 |
|---|---|---|
| L1 | 行 | `0 1px 2px rgba(20,40,90,.04)` |
| L2 | 卡片 | `0 10px 30px rgba(20,40,90,.06)` |
| L3 | 弹层 / 菜单 | `0 12px 32px rgba(20,40,90,.14)` |
| L4 | 窗口 / 对话框 | `0 24px 60px` · 深色用 `rgba(0,0,0,.18)` |

模糊：顶栏 `blur(28) saturate(180%)`，侧栏与面板 `blur(40)`，对话框 `blur(20)`。

## 1.4 组件与状态

状态过渡统一 80–120ms ease-out，只动底色与描边，不动尺寸与位移。

### 1.4a 按钮

高 32，圆角 8，左右内距 14，图标与文字间距 7，字号 12.5 / 600（次级 400）。

| 状态 | 取值 |
|---|---|
| 主 · 默认 | `#5b8dff`，白字，`0 4px 10px rgba(91,141,255,.3)` + `inset 0 1px 0 rgba(255,255,255,.25)` |
| 主 · 悬停 | `#7ba3ff`（亮 8%），`0 6px 14px rgba(91,141,255,.36)` |
| 主 · 按下 | `#4a76d9`（暗 10%），去掉投影 |
| 主 · 禁用 | `rgba(91,141,255,.3)`，文字 white 55% |
| 次级 | white 6% + 描边 white 10%，文字 white 86% |
| 幽灵 | 无底，文字 white 62%；悬停才出底 |
| 危险 | `rgba(255,120,150,.18)` + 描边 34%，文字 `#ff9db3`；只在确认弹层内用实色 |

图标按钮 32×32，圆角 9：默认 white 5% / 悬停 white 10% / 激活 accent 22% + 描边 40%；
角标 8px 圆点 `#5fd3bc`，外描 2px 窗口底色。

### 1.4b 输入框

高 32，圆角 10，内距 12；占位 white 42%，输入值 white 86%。

| 状态 | 取值 |
|---|---|
| 默认 | white 6% + `inset 0 1px 0 rgba(255,255,255,.05)` |
| 悬停 | white 9% |
| 聚焦 | white 8% + 描边 `rgba(91,141,255,.55)` + 外发光 `0 0 0 3px rgba(91,141,255,.16)` |
| 错误 | `rgba(255,120,150,.1)` + 描边 50%；错误文字 11px `#ff9db3` |
| 禁用 | white 3%，文字 white 30% |

搜索框：高 32 圆角 10，左图标 opacity .45，右侧快捷键胶囊 10px mono / 圆角 4 / white 7%。
下拉：同输入框 + 描边 white 8% + 右侧 `▾` white 45%。

### 1.4c 列表行

单行 34 / 双行 44，圆角 9，行间距 2；整行可点，右侧操作只在悬停时出现。

| 状态 | 取值 |
|---|---|
| 默认 | 无底，主文案 13px white 80% |
| 悬停 | white 6%，出现行内操作（高 22，圆角 7，white 10%） |
| 选中 | accent 16% + 描边 accent 24%，主文案白 600 |
| 多选 | accent 10% + 14px 圆角 4 的 accent 勾选框 |
| 进行中 | white 4% + 底部 2px accent 进度条，百分比 `#9fc0ff` |
| 失败 | `rgba(255,120,150,.1)`，标记文字 `#ff9db3` |
| 忽略 / 禁用 | opacity .45 |

表头 10.5px / 600 / 0.08em，底部 1px 描边，随内容滚动吸顶。不用斑马纹。

### 1.4d 卡片

内容卡圆角 12、内距 16；标题 13/600，正文 12/1.7，操作贴底右对齐；
悬停时投影升到 L2，不放大。

海报卡 2:3，圆角 10，标题在卡下方（12.5/600 + mono 11 副行）。
网格列宽 `minmax(148px,1fr)`，间距 18；选中时描边换成 accent 并加 3px 外发光。

### 1.4e 弹层 · 菜单 · 对话框 · Toast

圆角 12，描边 white 10%，投影 L3；菜单项高 30，左右内距 12，图标列宽 18。

- 菜单面板 `rgba(22,24,38,.92)` + blur 20，内距 5；分隔线 1px white 9%，左右留 8。
- 菜单项悬停 white 8%；快捷键 10px mono white 40%；危险项文字 `#ff9db3`；禁用 opacity .4。
- 对话框：标题 14/600，正文 12/1.7 white 62%；底部操作条 `white 3%` + 顶部描边 white 7%，
  内距 `12 18`，按钮右对齐，主操作永远在最右。最大宽 **560**，超过内容自身滚动。
- Toast：圆角 10，内距 `11 14`，左侧 8px 语义圆点，右侧行动文字 `#9fc0ff`；
  停留 3 秒，出现在顶栏下方居中，同时最多一条，新的替换旧的。
- 出现 120ms 向下 4px 淡入，关闭 100ms 向上 4px 淡出；点击外部、Esc、切换分区都关闭。

### 1.4f 动效

| 场景 | 时长 |
|---|---|
| 悬停 / 按下 | 80ms ease-out |
| 弹层出现 / 关闭 | 120 / 100ms |
| 抽屉与面板 | 180ms ease-in-out |
| 分区切换 | 不做转场 |
| 进度条更新 | 240ms linear |
| Toast 停留 | 3000ms |

- 只动不透明度、底色与 4px 内的位移；不做缩放、不做弹性曲线。
- 系统「减少动态效果」开启时全部改为瞬时切换，只保留不透明度渐变。
- 长任务超过 400ms 才显示进度；超过 10 秒给出可中断入口。

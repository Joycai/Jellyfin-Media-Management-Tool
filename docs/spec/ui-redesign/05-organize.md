## 5.4 撤销与历史

三种形态：抽屉（520 宽）、顶栏浮层（380 宽）、独立窗口（520 宽）。

### 顶栏浮层（主形态）

- 宽 **380**，最大高 **420**，超出内部滚动；圆角 12，与顶栏间距 8，
  箭头 11×11 旋转 45° 对齐历史按钮中心。
- 面板 `rgba(20,22,38,.92)` + blur 40 saturate 180 + 描边 white 10%
  + `0 24px 60px rgba(0,0,0,.55), inset 0 1px 0 rgba(255,255,255,.07)`。
- 头 `padding 14 16 10`：标题 13/600 + 计数胶囊 mono 10px · r4 · white 8%
  + 右侧「全部记录」11.5px `#7fa5ff`。
- 分组标题 10px / 600 / 0.08em white 35%，`padding 8 10 5`。
- 行高 **44**（26 图标 + 9 上下内距），圆角 9，gap 11；悬停 white 6%，
  最近一条默认高亮。
- 三段：类型图标 26 · r8（重命名蓝 `accent 20%` / 刮削青 `rgba(95,211,188,.18)` /
  AI 紫 `rgba(157,123,255,.2)` / 移动中性 white 7% / 删除红 `rgba(255,120,150,.16)`）、
  标题 12.5px + 时间路径 mono 11px white 45%、
  右侧撤销按钮 h24 · `padding 0 10` · r7 · white 10% + 描边 12%
  —— **仅在可撤销且悬停时出现**。
- 不可撤销项整行 55% 不透明度，副文案直接写「不可撤销」，不用禁用态按钮占位。
- 页脚 `padding 10 14` · 顶边 1px white 7%：左 11.5px 保留期，右 mono 10.5px `⌘Z 撤销上一步`。
- 点击浮层外、Esc、切换分区都关闭；关闭动画 120ms 向上 4px 淡出。
- Windows 版完全相同，仅 `⌘Z` → `Ctrl+Z`、圆角 12 → 10、投影加深一档。

> **保留期文案冲突**：浮层与独立窗口写「保留最近 30 天」，抽屉写「保留 7 天」。
> 实现以 `HistoryService.retentionDays = 7` 为准（真实行为），文案走 l10n。

### 历史按钮状态

| 状态 | 取值 |
|---|---|
| 默认 | white 5% |
| 悬停 | white 10% · 80ms |
| 浮层打开中 | `accent 22%` + 描边 40% |
| 有可撤销的新操作 | 8px 圆点 `#5fd3bc`，2px 窗口底色描边挖空，右上 `-2,-2` |
| 无历史 / 窗口失焦 | 灰度 + 50% 不透明 |

行为：
- 单击开浮层；`⌘Z / Ctrl+Z` 直接撤销最近一条，不开浮层，改用顶栏下方 3 秒 toast 反馈。
- 角标只在「最近一条操作可撤销且用户尚未打开过浮层」时出现，打开即消失，不做数字计数。
- 「全部记录」跳转独立窗口；独立窗口支持按类型筛选与导出日志。
- 撤销执行中该行显示 2px accent 进度条，完成后行淡出并从列表移除，**不做二次确认**。

  下方三段标签 10.5px：`无 / 柔和 / 强烈`。

  选中 `0 0 0 2px #fff, 0 0 0 4px <色>`；`＋` 为 ink 6% + 虚线描边。

### 强调色取色浮层

宽 **312**，锚定 `＋` 按钮右下、间距 8；r12 · `rgba(255,255,255,.94)` + 描边 ink 8%
+ `0 12px 32px rgba(20,40,90,.16)` · `padding 14`。
- SV 面板 h140 · r10（`linear-gradient(to top,#000,transparent)` 叠
  `linear-gradient(to right,#fff,<hue>)`）；游标 16 圆 · `2px #fff` 描边。
- 色相轨 h12 · r6 全色相渐变；把手 18 圆白。
- 透明度轨 h12 · r6（透明→当前色）；把手 18 圆白。
- 值行：34×34 · r9 当前色块 + `flex:1` h34 · r9 HEX 输入（聚焦环）+ 右侧 `HEX ▾`
  + 34×34 · r9 吸管 `⌖`。
- 「最近使用」标签 10px / 700 / 0.06em + 6 个 22×22 · r6 色块。
- 对比提示条 `padding 9 11` · r9 · `rgba(95,211,188,.14)` + 描边 30%：
  `✓` + `与深 / 浅两套底色对比 4.6:1 · 5.1:1`。
- 底部：「恢复默认蓝」11.5px `#3b5bc0` + 右侧「取消」/「应用」h30 · r8。

规则：
- 打开期间 `＋` 显示当前色并保持 4px 光环。
- 取色实时预览到整个界面，取消即回滚；Esc 取消，回车应用。
- 输入支持 `#RGB` / `#RRGGBB` / `rgb()` / `oklch()`，非法输入回退上一值。
- 透明度轨道只作用于强调色的底色层，文字与图标始终用不透明实色。
- 对比低于 3:1 时提示条转警告橙、注明「仅建议用于底色」，仍允许应用。
- 应用后加入最近使用（最多 6 个，先进先出）；预设 5 色不可删除。

### 路径与位置

- **媒体库根目录**：行内 32 图标 + 名称 + mono 路径 + 计数 + 状态徽标（已连接 / 未挂载）
  + 悬停「更改」；末尾「＋ 添加根目录」「重新扫描」。
- **默认位置**：整理输出位置（跟随对应根目录 / 选择…）、临时与下载目录。
- **收藏的路径**：可拖拽排序（`⋮⋮` 手柄），最多 8 个，与侧边栏「收藏」分组同步。
- **最近访问**：保留最近 20 条，悬停行尾 `☆` 可加入收藏，右上「清除记录」。

> 现状：`SettingsService` 的 favorites 上限与 recents（cap 8）需与设计稿的
> 「收藏 8 / 最近 20」对齐 —— **保持现有服务行为不变**，UI 只展示实际值；
> 上限调整计入 backlog。多根目录、挂载状态、重新扫描均为未实现能力 → 占位。

### 隐私与缓存

- **配置与数据位置**：配置文件夹（浏览 / 复制）、数据库与日志（导出）。
- **缓存**：元数据缓存 / 图片缓存 / 运行日志，各带大小与「清理」，末行合计 + 「全部清理」。
- **隐私**开关：发送匿名使用统计、崩溃报告、记录 AI 请求与回复正文、退出时清空临时目录。
- **危险操作**：重置所有数据 →「重置…」；二次确认弹层要求输入 `RESET`，
  可勾选「保留 AI 服务配置」，此操作不可撤销。

> 现状：应用无遥测、无 library.db。遥测两项 → 占位并默认关闭 + 禁用；
> 缓存分类按实际（thumbnails / undo blobs / agent workspace）落地。
